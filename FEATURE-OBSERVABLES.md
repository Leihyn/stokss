# stokss: Feature Observables

Each row is a verifiable test that the feature WORKS, not that it exists.
Generated by forge 2026-09-12.

## F-001: Detect a real corporate action from on-chain mint state

- **Observable:** parse_scaled_ui on a live mainnet mint returns the same multiplier the issuer API reports for that mint
- **Test:** `cargo test -p stokss --lib scaled_ui`
- **Sentinel failure:** parser returns None, or a multiplier that differs from api.backed.fi
- **Verified by:** Phase 1 gate

## F-002: Sell exactly the increment, never more

- **Observable:** after harvest, holder scaled balance >= pre-harvest scaled balance, and the delta transferred equals floor(R*(1-M0/M1)) to within one raw unit
- **Test:** `anchor test --skip-deploy`
- **Sentinel failure:** holder scaled balance decreases, or delta exceeds the computed value
- **Verified by:** Phase 1 and Phase 4 gates

## F-003: A tick can never be harvested twice

- **Observable:** a second harvest on the same tick fails with ZeroDelta and moves nothing
- **Test:** `anchor test --skip-deploy 2>&1 | grep idempotent`
- **Sentinel failure:** a second harvest succeeds and transfers a non-zero amount
- **Verified by:** Phase 1 gate

## F-004: Do not sell into a closed market

- **Observable:** with the market closed, a queued Dividend tick moves to waiting_for_open and no transfer occurs
- **Test:** `cd crank && pnpm start -- --once 2>&1 | grep 'queued for the open'`
- **Sentinel failure:** a harvest transaction is sent while marketState().open is false
- **Verified by:** Phase 3 and Phase 4 gates

## F-005: Pay the holder real USDC

- **Observable:** the destination token account balance increases by the settle amount, and an on-chain HarvestReceipt exists with a matching usdc_paid
- **Test:** `solana account <DESTINATION_ATA> --output json | jq '.account.data.parsed.info.tokenAmount.uiAmount'`
- **Sentinel failure:** receipt written with usdc_paid > 0 but no balance change
- **Verified by:** Phase 4 and Phase 7 gates

## F-006: Reverse splits and administrative changes are never harvested

- **Observable:** a tick whose issuer reason is not Dividend is stored with state=skipped and produces no harvest
- **Test:** `cargo test -p stokss --lib reverse_split_is_rejected`
- **Sentinel failure:** a Split or ReverseSplit event produces a non-zero delta
- **Verified by:** Phase 1 gate

## F-007: Show the holder what was quietly reinvested

- **Observable:** /api/backfill?symbol=KOx returns tickCount 4 and a positive totalUsd, matching KOx's four real dividend ticks
- **Test:** `curl -s 'http://localhost:3000/api/backfill?symbol=KOx&rawAmount=100000000&price=89.28&decimals=8' | jq '.tickCount'`
- **Sentinel failure:** tickCount 0, or a total computed from anything other than real multiplier history
- **Verified by:** Phase 6 gate

## F-008: The custody cap is real and visible

- **Observable:** spl-token display on the holder ATA shows a delegate equal to the harvest authority PDA and a delegated amount well below the balance
- **Test:** `spl-token display <HOLDER_ATA> | grep -A1 Delegate`
- **Sentinel failure:** delegated amount equals the full balance, or no delegate is set after enrollment
- **Verified by:** Phase 6 gate
